# 本地网页访问（WEB-ACCESS）

把 FlowPilot 暴露成浏览器可用的本地网页，两种模式**互相独立**（各自开关、端口、链接，可单独开/关）：

| 模式 | 链接示例 | 能力 | 鉴权 |
|---|---|---|---|
| **只读看板** | `http://127.0.0.1:4173/` | 今日推荐、可推进/待跟进/逾期计数、项目进度；10 秒自动刷新 | 无（只读，GET only） |
| **远程工作台** | `http://127.0.0.1:4174/?token=…` | 今日/项目/节点详情；推进节点、开始/完成/等待/阻塞/跳过/重开、双角色确认、改计划时间、写备注、增删链接 | **访问口令**（链接含 token，或登录页输入） |

两者都只绑定 `127.0.0.1`，不需要 DSH Web UI 就能用；适合手机/平板连到本机时远程操作（通过端口转发/反向代理自行承担风险，见「安全边界」）。

## 使用

1. DSH → FlowPilot → **设置** → 「网页访问 · 只读看板」/「网页访问 · 远程工作台」；
2. 打开开关（默认端口 4173 / 4174，可改 1024–65535）→ 点「应用」；
3. 复制链接在浏览器打开：
   - 只读看板：直接打开；
   - 远程工作台：复制「含口令链接」打开（等价于先打开登录页再粘贴口令）；
4. 远程工作台右上角「退出」清除本机保存的登录 Cookie。

## 远程工作台能做什么

- 看：今日推荐 / 等待跟进 / 近期截止；按业务线分组的项目与流程节点；
- 推进：开始处理、标记完成（证据/双角色门槛仍由宿主校验）、等待、阻塞、跳过、重新打开；
- 审批：设计/产品通过、退回（退回原因必填）；
- 计划：计划开始 / 计划完成 / 下次跟进（清空即删除）；
- 记录：节点备注、关联链接（类型 + URL，可删除）。

> 写操作走宿主同一套 `engine.dispatch`，与面板行为一致（证据门槛、解锁、归档只读等规则都生效）；活动记录 actor 记为 `web`。

## 安全边界

| 项 | 说明 |
|---|---|
| 绑定 | 固定 `127.0.0.1`，局域网其它设备默认访问不到 |
| 只读看板 | 只有 `GET /` 与 `GET /api/summary`；POST 一律 405 |
| 远程工作台 | 除登录页外，所有页面/API 都要口令；口令错误返回 401 |
| 口令 | 开启时自动生成（24 字符）；可在设置里复制或「重新生成」（旧口令立即失效）；只存在本机 `<dataDir>/web-access.json` |
| 链接 | 「含口令链接」把 token 放在 query；页面打开后服务端会种 `HttpOnly; SameSite=Strict` Cookie，后续请求不再暴露 token |
| 跨站 | 写接口要求 `application/json` 且 Origin/Host 同源，降低 CSRF 风险 |
| 会话 | Cookie 30 天；退出即清除；换端口/重新生成口令后旧链接失效 |

**不要把「含口令链接」发给别人**，也不要在公网做端口转发/内网穿透；如需公网使用，请自行加一层 HTTPS 反向代理 + 强口令。当前版本不支持绑定 `0.0.0.0`。

## HTTP 路由

### 只读看板（无鉴权，仅 GET）

| 路由 | 说明 |
|---|---|
| `GET /` | 只读看板页面（跟随系统深浅色） |
| `GET /api/summary` | 轻量摘要 JSON：计数 / 今日推荐 / 项目进度 |

### 远程工作台（需口令）

口令来源（任一）：Cookie `fp_web_token`、请求头 `x-flowpilot-token`、query `?token=`。

| 路由 | 方法 | 说明 |
|---|---|---|
| `/` | GET | 工作台页面（未登录时返回登录页） |
| `/login` | GET/POST | 登录页 / 提交口令（form-urlencoded 或 JSON `{token}`）→ 303 + Cookie |
| `/logout` | POST | 清除 Cookie → 303 `/login` |
| `/api/state` | GET | `{ok, revision, state, derived}`（与宿主 `/flowpilot/api/state` 同构） |
| `/api/action` | POST | body `{action, payload}` → `{ok, revision, state, derived, result}`；失败 `{ok:false, code, error}` |

`/api/action` 接受宿主全部写动作（`ACTION_NAMES`），校验与错误码和面板一致（如证据不足 `NEED_EVIDENCE`、状态不允许 `INVALID_STATE`）。

## 配置与文件

```jsonc
// <dataDir>/web-access.json（机器本地偏好；不进 data.json / 同步 / 导出）
{
  "readOnly": { "enabled": false, "port": 4173 },
  "full":     { "enabled": false, "port": 4174, "token": "本机生成的随机口令" }
}
```

- 旧配置 `{ enabled, port }` 会自动迁移为 `readOnly`；
- 插件加载时，上次开着的模式自动恢复监听；端口被占用只在设置里显示错误，不影响其它功能；
- 插件设置接口：`GET/POST /flowpilot/api/webaccess`
  - GET → `{ok, status: {readOnly, full, configFile}}`
  - POST → `{mode: 'readOnly'|'full', enabled?, port?, token?, regenerateToken?}`，返回最新 status。

## 排障

| 现象 | 处理 |
|---|---|
| 设置里显示启动失败/端口占用 | 换端口（两个模式不能用同一端口）；确认没有其它程序占用 |
| 远程工作台提示未授权 / 一直回登录页 | 用设置里的「含口令链接」重新打开；或点「重新生成」后复制新链接 |
| 链接能打开但改不了数据 | 检查是否用了只读看板的链接/端口；只读模式没有写接口 |
| 手机访问不到 | 当前只绑 127.0.0.1；需要自行做同网段转发（并评估安全风险） |
| 重启 DSH 后链接失效 | 开关是持久化的；若端口被占会保持关闭，重新在设置里开启 |

# 本地只读网页（WEB-ACCESS）

目标：不用打开 DSH，也能在任意浏览器里查看 FlowPilot 的今日待办与项目进度。
只读、只绑定 `127.0.0.1`、不需要任何凭据。

## 使用

1. DSH → FlowPilot → 设置 → **网页访问**；
2. 打开「本地只读网页」（默认端口 `4173`，可改 1024–65535），点右侧「应用」；
3. 复制下方链接，在浏览器打开：`http://127.0.0.1:4173/`。

页面每 10 秒自动刷新，展示：可推进 / 待跟进 / 逾期计数、今日推荐节点、项目进度（当前阶段与完成度）。

## 行为

| 项 | 说明 |
|---|---|
| 绑定地址 | 固定 `127.0.0.1`（仅本机；不接受外部网卡） |
| 权限 | **只读**：只有 `GET /` 与 `GET /api/summary`，没有任何写入口 |
| 数据来源 | 运行中宿主的 `engine.snapshot()`（与面板同一份内存数据，含未落盘前的周报草稿补齐等） |
| 持久化 | `<dataDir>/web-access.json`（机器本地偏好，不进 `data.json`、不同步、不导出） |
| 启动 | 插件加载时若上次是开启状态，会自动恢复监听；端口被占用只在设置里显示错误，不影响其它功能 |
| 关闭 | 设置里关闭开关，服务立即停止监听 |

## HTTP 路由（宿主本体）

| 路由 | 方法 | 说明 |
|---|---|---|
| `/flowpilot/api/webaccess` | GET | 读取状态：`{enabled, running, host, port, url, startedAt, error}` |
| `/flowpilot/api/webaccess` | POST | `{enabled?: boolean, port?: number}` 开关或改端口，返回最新 status |

## 限制

- 只读：不支持完成任务、改配置、同步等写操作；
- 不提供认证：因为只绑定回环地址（本机浏览器可访问，局域网/手机默认不可）；
- 页面是独立静态实现，不加载 DSH 前端或插件 `client.js`，因此不依赖宿主版本。

# FlowPilot

跑在 DeepSeek Harness Web UI 里的**流程节点驱动项目管理面板**：把「业务线 → 项目 → 流程实例 → 节点」的推进过程放进一个三栏工作台。

## 功能

- **业务线与项目**：按业务线组织项目，项目挂「设计交付 / 验收」流程模板，自动展开节点
- **流程节点**：未解锁 / 待开始 / 进行中 / 待确认 / 已阻塞 / 待修改 / 已完成 / 已跳过，支持退回与轮次
- **双角色确认**：设计与产品分别确认，可配置完成证据（设计稿 / Figma / 文档 / 讨论记录 / 测试等）
- **今日队列**：推荐处理、等待跟进、近期截止，配合节奏感知与日终交接
- **周报**：按节点事件自动汇总，可编辑、可复制 Markdown
- **AI 建流程**：粘贴 PRD 直接生成项目与流程节点
- **同步**：GitHub / WebDAV，记录级三方合并 + 冲突审阅
- **本地网页访问**：只读看板，以及带访问口令的远程工作台（仅绑定本机回环地址）
- **版本检查与更新记录**

## 安装

DSH → 设置 → 插件 → 添加插件，仓库地址：

```
https://github.com/Hazen223/dsh-flowpilot-public
```

固定版本可写 `...#v1.9.2`；安装后按提示重启 DSH。数据保存在本机，可随时导出备份。
